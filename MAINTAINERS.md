# Maintainers

Roles are held by the Jiji Labs team (PT JIJI LABS DIGITAL), acting through the GitHub org `@swellchat`. This file lists roles, not people. How roles are given and taken away is in `GOVERNANCE.md`.

| Role | Held by | What it does |
|---|---|---|
| Lead maintainer | Jiji Labs team (`@swellchat`) | Final call when maintainers disagree, releases, governance changes |
| Security contact | Jiji Labs team (`@swellchat`) | Receives vulnerability reports, sets severity, coordinates fixes and advisories |
| Spec editor | Jiji Labs team (`@swellchat`) | Keeps `docs/SWELL-PROTOCOL-SPEC.md`, the vectors and the threat model in step |
| Swift maintainer | Jiji Labs team (`@swellchat`) | `ios/SwellProtocol` |
| Kotlin maintainer | Jiji Labs team (`@swellchat`) | `android/swellprotocol`, `android/fuzz` |
| Formal models | Jiji Labs team (`@swellchat`) | `docs/formal/`, `docs/FORMAL-RESULTS.md` |
| Code of conduct contact | Jiji Labs team (`@swellchat`) | Receives and handles conduct reports |
